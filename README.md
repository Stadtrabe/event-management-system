# Event Management System

## Projektbeschreibung

Entwicklung eines webbasierten Veranstaltungsmanagementsystems mit rollenbasierter Rechteverwaltung.

Benutzer können Veranstaltungen suchen, Interesse bekunden oder sich zu Veranstaltungen anmelden. Veranstalter können eigene Veranstaltungen verwalten. Administratoren übernehmen Verwaltungs- und Moderationsaufgaben.

## Technologien

- PHP 8
- MySQL / MariaDB
- PDO
- Bootstrap 5

## Entwicklungsumgebung
- Visual Studio Code
- MySQL Workbench
- GitHub
- XAMPP

## Rollen

### Benutzer (User)

- Registrierung
- Login / Logout
- Profil bearbeiten
- Veranstaltungen suchen und ansehen
- Veranstaltungen als „Interessiert“ markieren
- Veranstaltungen als „Angemeldet“ markieren
- Markierungen entfernen
- Eigene Veranstaltungen einsehen

### Veranstalter (Organizer)

- Veranstaltungen suchen und ansehen
- Veranstaltung erstellen
- Veranstaltung bearbeiten
- Veranstaltung löschen
- Eigene Veranstaltungen verwalten
- Teilnehmerliste einsehen

### Administrator (Admin)

- Benutzerverwaltung
- Rollenverwaltung
- Veranstaltungsverwaltung
- Übersicht und Statistik

## Projektziel

Ziel des Projekts ist die Entwicklung eines übersichtlichen und benutzerfreundlichen Systems zur Organisation und Verwaltung von Veranstaltungen.

# (ENG)

# Event Management System

## Project Description

Development of a web-based event management system with role-based access control.

Users can browse events, mark events as interesting, or register for events. Organizers can manage their own events. Administrators are responsible for system management and moderation.

## Technologies

- PHP 8
- MySQL / MariaDB
- PDO
- Bootstrap 5
- Git & GitHub

## Roles

### User

- Registration
- Login / Logout
- Profile management
- Search and view events
- Mark events as "Interested"
- Register for events
- Remove event markings
- View own activities

### Organizer

In addition to user permissions:

- Create events
- Edit events
- Delete events
- Manage own events
- View participant lists

### Administrator

- User management
- Role management
- Event management
- System overview and statistics

## Project Goal

The goal of this project is to develop a clear and user-friendly system for organizing and managing events.
