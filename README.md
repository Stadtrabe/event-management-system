# Event Management System

## © 11/2026 Frederick Mäueler

## Projektbeschreibung

Entwicklung eines webbasierten Veranstaltungsmanagementsystems mit rollenbasierter Rechteverwaltung.

Benutzer können Veranstaltungen suchen, Interesse bekunden oder sich zu Veranstaltungen anmelden. Veranstalter können eigene Veranstaltungen verwalten. Administratoren übernehmen Verwaltungs- und Moderationsaufgaben.

Lernprojekt:
Umschulung Fachinformatiker für Anwendungsentwicklung

## Technologien

- PHP 8
- MySQL / MariaDB
- PDO
- Bootstrap 5

## Entwicklungsumgebung
- Visual Studio Code
- MySQL Workbench
- GitHub
- XAMPP

## Rollen

### Benutzer (User)

- Registrierung
- Login / Logout
- Profil bearbeiten
- Veranstaltungen suchen und ansehen
- Veranstaltungen als „Interessiert“ markieren
- Veranstaltungen als „Angemeldet“ markieren
- Markierungen entfernen
- Eigene Veranstaltungen einsehen

### Veranstalter (Organizer)

- Veranstaltungen suchen und ansehen
- Veranstaltung erstellen
- Veranstaltung bearbeiten
- Veranstaltung löschen
- Eigene Veranstaltungen verwalten
- Teilnehmerliste einsehen

### Administrator (Admin)

- Benutzerverwaltung
- Rollenverwaltung
- Veranstaltungsverwaltung
- Übersicht und Statistik

## Projektziel

Ziel des Projekts ist die Entwicklung eines übersichtlichen und benutzerfreundlichen Systems zur Organisation und Verwaltung von Veranstaltungen.

# (ENG)

## Project Description

Development of a web-based event management system with role-based access control.

Users can browse events, express interest in events, or register for participation. Organizers can create and manage their own events, while administrators are responsible for user, role, and event management.

Learning Project

Developed as part of a retraining program for IT Specialist in Application Development.

## Technologies

- PHP 8
- MySQL / MariaDB
- PDO
- Bootstrap 5

## Development Environment

- Visual Studio Code
- MySQL Workbench
- GitHub
- XAMPP

## Roles

### User

- Registration
- Login / Logout
- Profile management
- Search and view events
- Mark events as "Interested"
- Register for events
- Remove event markings
- View personal events and activities

### Organizer

In addition to the basic user permissions:

- Profile management
- Search and view events
- Create events
- Edit events
- Delete events
- Manage own events
- View participant lists

### Administrator

- User management
- Role management
- Event management
- Dashboard and statistics

## Project Goal

The goal of this project is to develop a clear and user-friendly system for organizing and managing events.

The application should provide role-based access control, allowing users to participate in events, organizers to manage events, and administrators to oversee the entire platform.
